# BidVibe API (Spring Boot)

BidVibe API la backend cho nen tang dau gia vat pham truc tuyen BidVibe.

Du an tap trung vao trai nghiem dau gia real-time, mua ban giua nguoi dung va he thong vi tien ao minh bach.

## Gioi thieu ngan gon

BidVibe cho phep nguoi dung:
- Tao va quan ly vat pham dau gia
- Tham gia cac phien dau gia theo thoi gian thuc
- Theo doi vat pham yeu thich, nhan thong bao cap nhat
- Mua ban lai vat pham tren cho den (market P2P)

He thong admin ho tro:
- Duyet vat pham va dieu phoi phien dau gia
- Quan ly giao dich nap/rut
- Kiem duyet nguoi dung va thong ke hoat dong

## Cong nghe chinh

- Java + Spring Boot
- Spring Security
- Spring Data JPA
- Spring WebSocket
- PostgreSQL
